# 🚗 Análise de Vendas de Carros com Tabela Dinâmica

Este projeto foi desenvolvido no **Excel**, utilizando **Tabelas Dinâmicas** para analisar uma base fictícia de vendas de carros.  
O objetivo foi consolidar informações de duas planilhas diferentes (**Lojas** e **Vendas**) em uma única visão analítica.

## 🔎 Estrutura da Análise
A Tabela Dinâmica traz os seguintes indicadores:
- **Lojas e cidades**  
- **Modelo de carro**  
- **Quantidade vendida**  
- **Faturamento**  
- **Comissão**  
- **Lucro**  

## 🛠️ Técnicas Utilizadas
- Integração de duas planilhas (Lojas e Vendas)  
- Criação de relacionamento entre as tabelas  
- Estruturação de uma **Tabela Dinâmica** consolidando múltiplas métricas  
- Organização dos dados em visão analítica para tomada de decisão  

## 🚀 Objetivo
Este projeto mostra como o **Excel** pode ser utilizado para criar insights rápidos e eficazes através de tabelas dinâmicas, mesmo em análises simples.
